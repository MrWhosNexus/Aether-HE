## Decisions Made
- **Host effect FPS stays 60**; per-frame allocation cuts instead of rate changes.
- **Mini panel never talks to the board**: it sets `pattern`/`speed` in the React app (`window.__aetherTraySet`) so the per-board dispatch table and settings persistence stay the single path. Rationale: one lighting code path, and the panel works for every board the app supports.
- **`startMinimized` lives in settings.json**, not in the Run registry command, so the toggle needs no registry rewrite; `--minimized` remains a CLI override.
- **Aether owns its WebView2 profile folder** (`%LOCALAPPDATA%\AetherHE\webview`); accepted the one-time reset of localStorage-only flags.
- **Fixed-mode (0) actuation preserves stored RT intervals** by RMW, fallback 1/1 (the board's factory pair), matching vendor `setAnyTriggerValue`.
- **Remap/switch/macros are read-modify-write and abort before writing** if the read-back fails, rather than writing a rebuilt table blind.
- **Did not rewrite `main` history** to make the first two commits self-contained: main was already pushed and the release tag targets the tip.
- Release was tagged with several changes hardware-unverified at the user's explicit request ("Release v0.5.0 now").
